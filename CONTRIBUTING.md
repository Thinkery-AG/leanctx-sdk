# Contributing

External code contributions are not accepted for the initial SDK release.

Issues and feature requests are welcome after the final repository opens them.
Security reports must use GitHub Private Vulnerability Reporting. Do not place
secrets, prompts, customer data, proprietary source, or credentials in an
issue.

Thinkery AG may change this policy later with explicit contributor terms. No
pull request, patch, or code submission is accepted under ambiguous copyright
terms.
